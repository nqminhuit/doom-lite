* Description :unfold:
This module adds [[https://golang.org][Go]] support through the built-in =go-ts-mode= (also =go-mod-ts-mode= and =go-work-ts-mode=), with LSP support via [[https://github.com/golang/tools/blob/master/gopls/README.md][gopls]] (see [[module::tools lsp]]).

- Build, run and test commands bound under the local leader
- Generate testing code (~go-gen-test~)

* Installation
[[id:01cffea4-3329-45e2-a892-95a384ab2338][Enable this module in your ~doom!~ block.]]

This module requires Go and a valid =$GOPATH=. ~gotests~ (for generating test code) and ~gopls~ (for LSP) are optional; ~doom doctor~ warns when they are missing.

** Go
- macOS: ~$ brew install go~
- Arch Linux: ~$ pacman -S go~
- openSUSE: ~$ zypper install go~

#+begin_src sh
export GOPATH=~/work/go

go install github.com/cweill/gotests/gotests@latest
go install golang.org/x/tools/gopls@latest
#+end_src

* Usage
** Keybinds
| Keys                | Description                                           |
|---------------------+-------------------------------------------------------|
| [[kbd:<localleader> b c]]   | run ~$ go clean~                                        |
| [[kbd:<localleader> b b]]   | run ~$ go build~                                        |
| [[kbd:<localleader> b r]]   | run ~$ go run .~                                        |
| [[kbd:<localleader> g f]]   | run ~go generate~ on the current file                 |
| [[kbd:<localleader> g d]]   | run ~go generate~ in the current directory, recursively           |
| [[kbd:<localleader> g a]]   | run ~go generate~ on the whole project                |
| [[kbd:<localleader> t t]]   | rerun last test                                       |
| [[kbd:<localleader> t a]]   | run all tests in project                              |
| [[kbd:<localleader> t f]]   | run all tests in current file                         |
| [[kbd:<localleader> t s]]   | run single test at point                              |
| [[kbd:<localleader> t n]]   | run nested tests at point                             |
| [[kbd:<localleader> t g]]   | Generate tests for all exported or selected functions |
| [[kbd:<localleader> t G]]   | Generate tests for all functions                      |
| [[kbd:<localleader> t e]]   | Generate tests for all exported functions             |
| [[kbd:<localleader> t b s]] | go test.bench single                                  |
| [[kbd:<localleader> t b a]] | go test.bench all                                     |
