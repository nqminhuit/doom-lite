* Description :unfold:
This module adds [[https://golang.org][Go]] support through the built-in =go-ts-mode= (also =go-mod-ts-mode= and =go-work-ts-mode=), with LSP support via [[https://github.com/golang/tools/blob/master/gopls/README.md][gopls]] (see =:tools lsp=).

- Build, run and test commands bound under the local leader
- Generate testing code (~go-gen-test~)

* Installation
Enable this module in your ~doom!~ block.

This module requires Go and a valid =$GOPATH=. ~gotests~ (for generating test code) and ~gopls~ (for LSP) are optional; ~doom doctor~ warns when they are missing.

** Go
- macOS: ~$ brew install go~
- Arch Linux: ~$ pacman -S go~
- openSUSE: ~$ zypper install go~

#+begin_src sh
export GOPATH=~/work/go

go install github.com/cweill/gotests/gotests@latest
go install golang.org/x/tools/gopls@latest
#+end_src

* Usage
** Keybinds
| Keys                | Description                                           |
|---------------------+-------------------------------------------------------|
| =<localleader> b c=   | run ~$ go clean~                                        |
| =<localleader> b b=   | run ~$ go build~                                        |
| =<localleader> b r=   | run ~$ go run .~                                        |
| =<localleader> g f=   | run ~go generate~ on the current file                 |
| =<localleader> g d=   | run ~go generate~ in the current directory, recursively           |
| =<localleader> g a=   | run ~go generate~ on the whole project                |
| =<localleader> t t=   | rerun last test                                       |
| =<localleader> t a=   | run all tests in project                              |
| =<localleader> t f=   | run all tests in current file                         |
| =<localleader> t s=   | run single test at point                              |
| =<localleader> t n=   | run nested tests at point                             |
| =<localleader> t g=   | Generate tests for all exported or selected functions |
| =<localleader> t G=   | Generate tests for all functions                      |
| =<localleader> t e=   | Generate tests for all exported functions             |
| =<localleader> t b s= | go test.bench single                                  |
| =<localleader> t b a= | go test.bench all                                     |
