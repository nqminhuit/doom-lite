* Description :unfold:
This module adds [[https://www.javascript.com/][JavaScript]] and [[https://www.typescriptlang.org/][TypeScript]] support to Doom Emacs.

- JSX/TSX support through the built-in =js-ts-mode=, =typescript-ts-mode= and =tsx-ts-mode=
- LSP integration through =:tools lsp= (code completion, jump-to-definitions and references)
- Syntax checking (with =:checkers syntax=)
- Node stack traces are parsed in compilation buffers
- A REPL (~+javascript/open-repl~, with =nodejs-repl=)

* Installation
Enable this module in your ~doom!~ block.

This module requires [[https://nodejs.org/en/][NodeJS]] and one of [[https://www.npmjs.com/][NPM]] or [[https://yarnpkg.com/][Yarn]] in your =$PATH=.

- MacOS: ~$ brew install node~
- Arch Linux: ~$ pacman --needed --noconfirm -S nodejs npm~
- openSUSE: ~$ zypper install nodejs npm~
