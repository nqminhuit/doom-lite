* Description :unfold:
This module augments the built-in =electric= package with keyword-based indentation (as opposed to character-based), makes RET continue commented lines (~+electric-continue-comments~), and enables ~electric-pair-mode~. ~set-electric!~ registers electric characters and words per major mode.
