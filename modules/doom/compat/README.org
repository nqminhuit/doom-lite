#+title:     :doom compat
#+subtitle:  Backwards compatibility with Doom v2
#+created:   June 06, 2026
#+since:     26.06.0

#+begin_quote warning
*This module is hardcoded to be enabled until v3 is released.* Its flags can't
be customized yet, but are documented here as a reference for posterity.

Also, because this is a compatibility module, its packages will rarely be bumped
(except to resolve upstream breakage) and it won't be developed to support new
features. If you need newer versions, I recommend you install the package
manually instead of relying on this module!
#+end_quote

* Description :unfold:
This module keeps the v2 =use-package!= and =map!= macros (and the pre-3.0 =IS-MAC=, =IS-LINUX=, =IS-WINDOWS= and =IS-BSD= variables, which live in core) working until v3.

For what to use instead, see the Usage section below.

  Define [[fns:map!]], [[fns:define-key!]], [[fns:undefine-key!]] and [[fns:define-localleader-key!]]. Always enabled.
