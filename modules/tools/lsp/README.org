* Description :unfold:
This module integrates [[https://langserver.org/][language servers]] into Doom Emacs through the built-in =eglot=. They provide features you'd expect from IDEs, like code completion, realtime linting, language-aware =imenu=/=xref= integration, jump-to-definition/references support, and more.

Eglot's list of supported servers (and how to register more) is [[https://github.com/joaotavora/eglot?tab=readme-ov-file#connecting-to-a-server][on its README]]. Each of Doom's :lang modules may add new, extend existing, or change support for existing LSP clients; ~set-eglot-client!~ registers a server for a major mode.

* Installation
Enable this module in your ~doom!~ block.

To get LSP working, you'll need to do two things:

1. Enable this module,
2. Install a language server appropriate for your targeted language(s).

The :lang modules start eglot in their buffers with ~lsp!~. Eglot will not install servers for you.

* Configuration
~+lsp-defer-shutdown~ (default 3) is the number of seconds to wait before shutting down a server after its last buffer is closed; set it to nil or 0 to shut down immediately.

* Troubleshooting

** My language server is not found
Make sure the server executable is on the =PATH= of the Emacs (or daemon) process.

** LSP/Eglot is not started automatically in my buffer
Eglot only starts when a client is defined for the buffer's major mode (see ~eglot-server-programs~ and ~set-eglot-client!~).
