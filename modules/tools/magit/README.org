* Description :unfold:
This module provides Magit, an interface to the Git version control system.

** Packages
- [[package:magit]]
- [[package:transient]] (built-in)
- [[package:cond-let]]

Evil keybindings come from =evil-collection-magit= ([[module::editor evil]]).

** Hacks
- [[package:magit]] has been modified to revert repo buffers (e.g. after changing branches) when you later switch to them, rather than all at once (~+magit-auto-revert~).
- ~magit-uniquify-buffer-names~ is disabled so two projects with the same name don't share magit buffers.

** Enable Gravatars
To enable gravatars when viewing commits:
#+begin_src emacs-lisp
;; in $DOOMDIR/config.el
(with-eval-after-load 'magit
  (setq magit-revision-show-gravatars '("^Author:     " . "^Commit:     ")))
#+end_src

** Enable granular diff-highlights for all hunks
By default, changes are highlighted *linewise* for all but the selected hunk.
This is so for [[https://magit.vc/manual/magit/Performance.html][performance reasons]]. You can enable character-wise highlights for
/all/ visible hunks with:
#+begin_src emacs-lisp
;; in $DOOMDIR/config.el
(with-eval-after-load 'magit
  (setq magit-diff-refine-hunk 'all))
#+end_src
