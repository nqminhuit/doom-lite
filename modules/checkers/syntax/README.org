* Description :unfold:
This module provides syntax checking and error highlighting, powered by the built-in =flymake=.

** Maintainers
/This module has no dedicated maintainers./

** Module flags
/This module has no flags./

** Packages
- =flymake=

** Hacks
- The emacs-lisp flymake byte-compile checker only runs in project buffers (mitigates CVE-2024-53920).
- ~next-error~ and ~previous-error~ are routed to flymake in buffers where it is active, and consult the current buffer first.

* Installation
Enable this module in your ~doom!~ block.

This module has no direct requirements, but some languages may have their own requirements to fulfill before you get syntax checking in them.
