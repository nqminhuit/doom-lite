#+title:    :ui workspaces
#+created:  February 20, 2017
#+since:    2.0.0

* Description
Workspaces built on the built-in =tab-bar=. Each workspace is a tab holding a window layout.

- The tab bar itself is hidden; =SPC TAB TAB= (or any switch command) lists the tabs in the echo area.
- Tabs are per-frame. There is no buffer isolation: the buffer list is global, and =SPC b b= is scoped to the current project instead.
- Switching project (=project-switch-project=) creates or reuses a workspace named after the project; an untouched =main= workspace is renamed instead.
- Nothing is persisted per workspace. Use =SPC TAB R= to restore the last desktop session.

* Commands
| Command                      | Key                | Description                         |
|------------------------------+--------------------+-------------------------------------|
| ~+workspace/display~         | [[kbd:SPC TAB TAB]]    | Show the workspaces in the echo area |
| ~+workspace/switch-to~       | [[kbd:SPC TAB .]]      | Switch by name (or index with a prefix arg) |
| ~+workspace/other~           | [[kbd:SPC TAB `]]      | Switch to the previous workspace    |
| ~+workspace/new~             | [[kbd:SPC TAB n]]      | New workspace                       |
| ~+workspace/new-named~       | [[kbd:SPC TAB N]]      | New workspace with a name           |
| ~+workspace/kill~            | [[kbd:SPC TAB d]]      | Kill this workspace (never the last) |
| ~+workspace/rename~          | [[kbd:SPC TAB r]]      | Rename this workspace               |
| ~+workspace/switch-right~    | [[kbd:SPC TAB ]]]      | Next workspace (wraps)              |
| ~+workspace/switch-left~     | [[kbd:SPC TAB []]      | Previous workspace (wraps)          |
| ~+workspace/switch-to-N~     | [[kbd:SPC TAB 1..9]]   | Switch to the Nth workspace         |
| ~+workspace/switch-to-final~ | [[kbd:SPC TAB 0]]      | Switch to the last workspace        |
