* Description :unfold:
This module provides a set of reasonable defaults, including:

- A Spacemacs-inspired keybinding scheme (leader keys in =+evil-bindings.el=)
- Custom =help-map= keys (~SPC h d m~ opens a module's README, ~doom/describe-package~, ~load-theme~ on [[kbd:C-h t]], ...)
- Smarter =C-a= / =C-e= and RET variants
